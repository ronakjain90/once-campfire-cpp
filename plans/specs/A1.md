Owns: the controllers, models, templates and route files of this area in `src/app/`, `src/models/`, `src/views/` (one file per controller or template; do not edit files of other areas), `tools/diffsweep/lists/*A1*` (only to add missing requests).

## Scope

- Session transfers (`/session/transfers/:id`, show and update; the 4-hour signed transfer id; QR code links if the page shows them).
- First run (`/first_run`: new and create, the admin account, the first room, the redirect rules when an account exists).
- Join links (`GET/POST /join/:join_code`: the user sign-up form, validation errors, the new user's memberships of all open rooms, sign-in after join).
- Welcome (`/`: redirect to the last room or the first room, the `last_room` cookie rules).
- IP bans (`BlockBannedRequests`) and user deactivation effects on sign-in.
- User agents and platform: `allow_browser` (the unsupported-browser page) and `set_platform`, matching `spec/vectors/campfire_user_agents.json` exactly (all cases).
- Every template in `.ct`, line for line from its ERB file; layout regions print their own indent and newline (agent brief, "Rules learned").
