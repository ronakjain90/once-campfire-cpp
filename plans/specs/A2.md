# A2: Rooms, the sidebar and message display

Owns: the controllers, models, templates and route files of this area in `src/app/`, `src/models/`, `src/views/` (one file per controller or template; do not edit files of other areas), `tools/diffsweep/lists/*A2*` (only to add missing requests).
Uses: everything on `main`: the A0 framework, A1, `src/richtext` (message bodies), `src/storage` (attachment and avatar URLs).
Behavior: Rails `reference/app/controllers/{rooms,rooms/*,users/sidebars}_controller.rb`, `messages_controller.rb#index` (the paged messages list), their models, helpers and views, including `messages/_message` and the other partials that show a message. Exact bytes and deliberate differences: the Rust port (`once-campfire-rust/crates/campfire/src/controllers/{rooms*,presenters*,messages.rs}`, `crates/views`).

**Split with A3:** A2 owns the READ side of messages: the message partials, `GET /rooms/:id` (with `@:message_id`), `GET /rooms/:id/messages` (paging with `before`/`after`), and the room refresh. A3 owns the WRITE side (create, edit, delete, boosts, the bot API, broadcasts) and reuses A2's partials.

## Scope

- Rooms: show (and `/rooms/:id/@:message_id`), index, destroy; open, closed and direct rooms (new, create, edit, update, destroy); involvements; refreshes; settings; the "last room" cookie; `set_room` and its redirect with the alert.
- The sidebar (`/users/me/sidebar`): rooms, direct rooms, unread state, the stream tags.
- Message display: the message partials with the fragment cache (`cache [message, "presentation-v3"]`), boosts shown, attachments shown, rich text bodies through `src/richtext`, the day separators and the paging links.
- **Performance is the point of this project.** The room page, the messages page and the sidebar are benchmark routes. Use the page cache (architecture 6.1) for them, with all inputs in the key (the dependency scope plus facets). Run each statement Rust runs, or fewer when the result is the same (G3 capture: `gate/capture/summary.md`). Do not render on a cache hit.
- Two A1 sweep requests depend on this area: `GET /rooms/:id` after sign-out must redirect to sign-in as Rust does.
