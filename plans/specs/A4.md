## Scope

- Account: edit and update (name, settings such as restricting room creation), the users list and admin actions (roles, deactivation, which destroys sessions and disconnects sockets: call a hook, A7 wires sockets), bots (create, edit, update, destroy, key reset), the join code reset, the logo (show with variants and `fresh_account_logo`, destroy), custom styles (edit and update).
- Users: show, the profile (show, edit, update: name, bio, email, password, avatar upload through `src/storage`), avatars (`/users/:token/avatar` with signed avatar tokens, the initials SVG for users without an avatar, variants, cache headers), bans (create, destroy, with the IP ban rows).
- Push subscriptions (index, create, destroy) and test notifications (enqueue only; delivery is A9).
- QR codes (`/qr_code/:id`): port `rqrcode` output exactly (`once-campfire-rust/crates/campfire/src/controllers/qr_code/rqrcode.rs`).
- The A1 sweep request `GET /users/me/profile` must match.
- **Performance:** `/users/:token/avatar` is a benchmark route (Rust: 390k req/s at 16 clients). Serve it from memory with the right cache headers; no database read on a hit if the result cannot change.
