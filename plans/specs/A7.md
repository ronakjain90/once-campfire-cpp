# A7: Action Cable channels

Owns: `src/app/channels/` (new), the WebSocket upgrade wiring in `src/net/` (keep it small), the cable setup in `src/app/main.cpp` and `src/app/app.cpp` (set `App::hub` and `App::turbo_broadcast`), `tools/diffsweep/lists/*A7*` (only to add missing requests).
Uses: `src/cable` (codec, protocol, `Connection`, `Hub`, `ChannelRegistry`), the A0 framework (session cookie authentication), the broadcast module `src/app/broadcasts.{hpp,cpp}` (rooms and messages already send through `deliver()`, which uses `app.hub` when it is set).
Behavior: Rails `reference/app/channels/**` (`application_cable/connection.rb`, the 7 channels: heartbeat, presence, read_rooms, room, room_messages, typing_notifications, unread_rooms), `Turbo::StreamsChannel` with `concerns/room_streams_are_authorized.rb`. Exact bytes and limits: the Rust port (`once-campfire-rust/crates/campfire/src/channels*`, `crates/cable`) and the Rust README ("Cable limits", "WebSockets").

Other agents work on search and on jobs and integrations at the same time: do not edit their files.

## Scope

1. `GET /cable`: the WebSocket upgrade in the worker that owns the connection, `permessage-deflate`, authentication from the `session_token` cookie (reject unauthorized as Rust does), the origin check.
2. Transport glue for `src/cable/connection.hpp`: `Transport::send` with `writev`, `close(grace)`, the lag limit (`on_lagged`), the 30-second write stall (`on_write_stall`), `on_closed`.
3. Hub wiring: one hub for the process; each worker drains its queue on its `eventfd`; set `App::hub` at boot before the workers start.
4. The 7 channels and `Turbo::StreamsChannel` with the room stream authorization patch: subscribe, reject, perform actions (presence, typing, read), the streams each one follows, the frames each one sends.
5. Revocation: removing a membership, deactivating or banning a user disconnects the user's sockets after commit (the account and user code calls a hook: find it and connect it).
