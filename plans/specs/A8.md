# A8: Front server

Owns: `src/net/front/` (new), and the changes in `src/net/` that the front server needs (keep them small and tell Opus which files you changed: A0 also builds on `src/net`). `tools/diffsweep/lists/*A8*` (TLS and HTTP/2 checks).
Uses: `src/core`, `src/net` (T5), `src/assets` (T9: precompressed bodies).
Spec: `plans/architecture.md` section 11. Behavior spec: `once-campfire-rust/crates/kit/src/front/` (TLS, ACME, HTTP/2, response cache, compression), the Rust README "Front server" and "Known differences". Ground truth for Thruster behavior: Thruster 0.1.x as the Rust port documents it.

## Scope

1. TLS with OpenSSL 3 and ALPN (`h2`, `http/1.1`), certificates from `TLS_DOMAIN` with automatic ACME (TLS-ALPN-01 and HTTP-01) as the Rust port does it, certificate storage in `/rails/storage/thruster` that Thruster can read and write (read the Rust code for the format), plain HTTP with `DISABLE_SSL`, the HTTP to HTTPS redirect rules.
2. HTTP/2 with nghttp2 in the worker event loop: streams map to the same handler path as HTTP/1.1; lowercase header names; the same limits.
3. The Thruster-compatible response cache (`CACHE_SIZE`, the key rules: count keys toward the size, keep raw paths and queries, skip URIs over 2 KB, forward range requests), `x-cache` headers, compression choice (which content types gzip or zstd, as Thruster does), `vary`.
4. Timeouts and limits: `HTTP_IDLE_TIMEOUT`, `HTTP_READ_TIMEOUT`, `HTTP_WRITE_TIMEOUT`, `MAX_REQUEST_BODY`, the shorter of idle and read timeouts until headers arrive (Rust README), HTTP/2 idle timeout.
5. `X-Forwarded-*` handling for `TARGET_PORT` and the trust rules.
6. Static asset serving through the T9 table with the same headers as `campfire-rust:app` (including the Thruster-added headers that T9 left out: `vary`, `x-cache`, `content-encoding`, `transfer-encoding`).
