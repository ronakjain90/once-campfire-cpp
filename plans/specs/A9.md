## Scope

- In-process queues, one for each job kind, with `JOB_CONCURRENCY` threads each (architecture section 13). Lost on a crash, as the Rust README says.
- Web Push: the VAPID keys (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`; invalid keys disable push at boot), RFC 8291 encryption and RFC 8292 VAPID with OpenSSL, the notification payload bytes, the truncation rules, the endpoint permit check, the timeouts, deletion of subscriptions on 404 and 410 or an invalid key, the test notification.
- Bot webhooks: the request bytes, the timeouts, the 100 MB reply limit, posting the bot's reply as a message (through the message area's code), the failure rules.
- Move the blob analyze and purge work that the message area runs inline into a job queue, if the Rust port runs it as a job.
- `RemoveBannedContentJob`: what a ban removes.
- Test against local HTTP servers only (no internet): a fake push service that checks the encryption (decrypt with the subscription's private key) and a fake webhook server.
