# T12: Storage

Owns: `src/storage/`.
Uses: `src/core`, `src/compat` (signed ids, Marshal and variation digests, Content-Disposition, MD5 and base64). Do not depend on `src/db` (T7): define plain structs for blob, attachment and variant rows, and functions that take and return them.
Spec: `plans/architecture.md` section 12. Behavior spec: `once-campfire-rust/crates/storage`, `crates/campfire/src/active_storage.rs`, the Rust README "Media formats" and "Media processing". Ground truth: Rails Active Storage in `campfire-reference:app`.

Media libraries: the dev image has Debian trixie's libvips and ffmpeg. The production image (`docker/Dockerfile`) builds libvips 8.16.1 and ffmpeg 7.1.5 as the Rust image does. Run the byte-identical media tests against the production versions: if the dev versions differ, run them in a container built from the `cpp-build` stage (`docker build --target cpp-build ...`).

## Scope

- Blob keys, checksums (MD5 base64), the disk layout `storage/files/ab/cd/<key>`, copy and checksum before rows are saved, delete.
- Signed blob ids, representation and variant URLs, the redirect and proxy URL formats.
- Variants with the libvips C API: every variant the app defines (`:thumb`, avatar `:square`, video poster `resize_to_limit`), the loader restrictions (`config/initializers/vips.rb`), byte-identical outputs.
- Analysis: image dimensions; video and audio duration, dimensions and bit rate through the ffmpeg libraries (the CLI only if the Rust port uses it); posters through ffmpeg with the 60 s and 30 s timeouts.
- Content type identification as Rails (Marcel) does for the app's cases. The Rust `crates/storage/src/tables.rs` is a large generated table: generate yours from the same source, do not copy it by hand.
- A bounded pool (at most 4) for media work.

## Acceptance (raw output in the report)

- `bin/dev build` and `bin/dev test` for release, asan, tsan pass (media tests may be release only if sanitizers break the C libraries; say so).
- The storage groups of `spec/vectors/storage.json`: case and pass table.
- Byte-identical variant, poster and metadata outputs for every file in `spec/vectors/storage/` with the production library versions (counts equal and different).
