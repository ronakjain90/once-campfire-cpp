# T13: Diff sweep

Owns: `tools/diffsweep/`.
Spec: `plans/architecture.md` section 16, oracle 2. Learn from `gate/bench/` (how it starts the Rust app with the right environment on a VM-local seed copy) and `gate/server/tests/compare.sh` (a small prototype of this tool).

## Scope

Python 3 and bash are fine. It runs in a container with `--network host`, like the benchmark runner (reuse `campfire-bench-runner` or extend it under `tools/diffsweep/`).

1. Start two apps (default expected `campfire-rust:app`, actual `campfire-cpp:app`; any two images by flag) on separate VM-local copies of a seed (default `default`; build missing seeds with `once-campfire-rust/parity/bin/seed` if needed), with the same environment, a frozen clock (`CAMPFIRE_FROZEN_TIME` at the seed's instant: read how `parity/bin/candidate` does it), and deliveries neutered as the benchmark does.
2. A request list format (YAML or JSON): sign in as a seed user (label from `labels.json`); plain requests with method, path, headers and body with `{{label}}` interpolation; capture values from a response for later steps; Action Cable sessions (connect, subscribe, perform, wait for N frames, compare frames); multi-actor sequences.
3. Comparison: status; header names and order; header values except an allowlist of volatile headers (`date`, `x-request-id`, `x-runtime`, random `set-cookie` values); decoded bodies (gzip, zstd) byte for byte, with normalizers only for values that are random by design; a unified diff of the first differing bytes for each request. Exit non-zero on any difference.
4. Request lists for every route and every state in `once-campfire-rust/parity/screens.yml`, and the request set of `once-campfire-rust/reference-tools/http_shape/sweep.py`, grouped by area (A1 to A9 as in `plans/tasks.md` wave 3), so each area can run only its list. Include write flows (post, edit, delete, boost, upload, sign in and out, join, admin edits), each in an isolated app pair or with resets.
5. `campfire-cpp:app` serves few routes now. Prove the tool by comparing `campfire-rust:app` with itself (zero differences) and with `campfire-reference:app` on a few pages (differences expected; show the report is clear).

## Acceptance (raw output in the report)

- Rust against Rust over all lists: zero differences (counts for each area).
- Rust against Rails on 5 requests: the diff output.
- A README with usage, the list format, and how to run one area.
