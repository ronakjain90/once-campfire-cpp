## Scope (no attachments, mentions, opengraph, autolink or plain text: those are T10)

- Gumbo at the version that Nokogiri vendors for the nokogiri version in `reference/Gemfile.lock` (done: Nokogiri 1.19.4). Record version and SHA-256 in `src/richtext/vendor/gumbo/VENDORED.md`. Match how `Nokogiri::HTML5` calls Gumbo (max tree depth 400, max attributes 400, max errors) and the Rust README "Malformed rich text" limits.
- A DOM (or direct use of the Gumbo tree) for fast sanitize and serialize: arena allocation, no `shared_ptr` per node.
- The serializer that matches Nokogiri's HTML5 serialization exactly (rules in `once-campfire-rust/crates/richtext/src/dom.rs` and the Nokogiri source).
- The sanitizer that matches Rails Action Text, rails-html-sanitizer and Loofah safe lists, with the Rust port's deliberate differences (README "Rich text attributes": drop `name` attributes; message pages drop styles; bot and webhook HTML keep only `color` and `background-color` with plain values). Read `once-campfire-rust/crates/richtext/src/sanitizer.rs` and the Loofah and Rails sources in `campfire-reference:app`.
- Tests: every case of the Rust rich text corpus that has no attachment, mention, autolink or plain text (corpus under `once-campfire-rust/crates/richtext` and `reference-tools/richtext`). Report counts: total corpus cases, cases in scope, passing.
- libFuzzer target `fuzz_richtext_sanitize` in `src/richtext/fuzz/`. Run it 5 minutes and report.
- Use the shared CMake helpers now (`campfire_library`, `campfire_test`; see `AGENTS.md`). Remove any throwaway top-level build files.
