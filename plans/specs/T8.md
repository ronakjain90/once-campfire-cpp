# T8: Templates

Owns: `src/views/` (foundation only), `src/routes/` (URL and path helpers), `tools/ctc.py`.
Uses: `src/core` (Out, SafeHtml, html_escape, Arena, time formats), `src/compat` (ERB escape rules, url_encode, JSON).
Spec: `plans/architecture.md` section 7.

## Scope

1. `tools/ctc.py`, the template compiler for `.ct` files, exactly as architecture 7.1 says: the params line, `{{ }}`, `{{= }}` that needs `SafeHtml` (a compile error otherwise; prove it with a negative compile test), if/elif/else/end, for, render partial, the cache block, `-%}` newline trim with ERB `-%>` rules, and the ERB source path comment. Generate readable C++: one function per template, declared in a generated header. CMake compiles every `src/views/**/*.ct` automatically. The fragment cache hook is an interface with a no-op default (the cache comes later).
2. `src/routes/`: path and URL helpers for every named route of `reference/config/routes.rb` (generate them from the routes file or a checked-in table). They must match `spec/vectors/campfire_routes.json` exactly, including the `fresh_account_logo` and `fresh_user_avatar` directs.
3. `src/views/helpers/`: Rails tag helpers with Rails attribute order and escape: `tag.x`, `content_tag`, `link_to`, `button_to` (the form markup Rails makes, without CSRF fields, per the Rust "Known differences"), `image_tag`, `time_tag`, `turbo_frame_tag`, Turbo Stream tags, the `form_with` and form builder methods that Campfire's views use, data and aria attribute expansion, class lists. Learn the exact output from `once-campfire-rust/crates/views/src/helpers/*`, and check against `once-campfire-rust/crates/views/tests/golden/` where they apply.
4. The layouts (`reference/app/views/layouts/*`) and the shared partials used by many pages, as `.ct` templates, byte-identical to the Rust golden outputs for the layout parts. If a layout needs data that does not exist yet (current user, account), define a plain struct for its inputs.

## Acceptance (raw output in the report)

- `bin/dev build` and `bin/dev test` for release, asan, tsan pass.
- `campfire_routes.json`: case and pass counts (all pass).
- ctc tests: each construct, whitespace and trim cases compared with ERB (run ERB in `campfire-reference:app` with `docker run --rm campfire-reference:app ruby -e ...` for expected output), and the SafeHtml negative compile test.
- Helper tests: the number of golden comparisons and passes.
